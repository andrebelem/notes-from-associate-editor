# Notes from an Associate Editor

This repository contains materials from the series **"Notes from an Associate Editor"**, where I share reflections on how scientific publishing works from the perspective of an Associate Editor.

The goal of this project is to provide a transparent, practical, and experience-based view of the editorial process, including peer review workflows, decision-making, and the role of emerging tools such as artificial intelligence.

## Contents

- **posts/**  
  Markdown versions of the original LinkedIn posts.

- **figures/**  
  Conceptual diagrams illustrating editorial workflows and processes.

- **prompts_for_gemini.md**  
  Prompts used to generate visual materials with AI tools.

## About the Figures

The figures in this repository were generated using AI tools based on the author's original conceptual design and editorial experience. They are intended as educational and illustrative material.

## Scope

The content reflects personal experience and does not represent any specific journal or publisher.
